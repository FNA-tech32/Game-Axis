## 🏃‍♂️ Local Setup &amp; Deployment

### 1. Clone the Repository
```bash
git clone https://github.com/game-axis/Game-Axis.git
cd Game-Axis
```

### 2. Run Locally via Any Static Server
Because Game Axis is engineered with zero runtime bloatware or heavy framework dependencies, it runs instantly in any modern web browser or lightweight HTTP server:

```bash
# Option A: Using Python 3 built-in HTTP server
python -m http.server 3000

# Option B: Using Node npx serve
npx serve .

# Option C: Using VS Code Live Server extension
# Right click on index.html and select "Open with Live Server"
```

Navigate to `http://localhost:3000` to inspect the live site.

### 3. Deploy to Production
Deploy in seconds to any static CDN host:
- **Vercel:** `npx vercel`
- **Netlify:** `npx netlify deploy --prod --dir=.`
- **GitHub Pages:** Push to `main` and enable GitHub Pages in repository settings.
